SERVICE COMMUNICATION MAP
═══════════════════════════════════════════════════════════════════════════════

SimulatorWindowTracker (Orchestrator)
  ├─ @Published simulators: [SimulatorWindow]
  ├─ @Published activeSimulator: SimulatorWindow?
  ├─ @Published isSimulatorFocused: Bool
  │
  ├── WindowObserver (per-PID AX listener)
  │   ├─ Notified by: kAXWindowMoved/Resized
  │   └─ Callback: onFrameChanged
  │
  ├── WindowEnumerator
  │   └─ Calls: CGWindowListCopyWindowInfo()
  │
  └── Device Type Cache
      └─ Updated by: simctl list devices --json


SideWindowController (Window Manager)
  ├─ Subscribes to: tracker.activeSimulator
  ├─ Subscribes to: tracker.isSimulatorFocused
  ├─ Owns: NSPanel with NSHostingView<SideWindowView>
  │
  ├── Shows/Hides based on:
  │   ├─ Simulator detected + focused
  │   └─ User preference: showSideWindow
  │
  ├── Collapse/Expand
  │   └─ Animation: SpringAnimator (0.3s spring or 0.1s linear)
  │
  └── Position Tracking
      ├─ Listens to: windowObserver.onFrameChanged
      └─ Uses: PositionCalculator (left/right/bottom/dynamic)


Feature Services (Independent)
  ├─ AXInspectorService
  │  ├─ Publishes: rootNodes: [AXNode]
  │  └─ Publishes: highlightFrame: CGRect?
  │
  ├─ BuildStatsService
  │  ├─ Polling: 5s interval
  │  └─ Publishes: recentBuilds: [BuildRecord]
  │
  ├─ EnvironmentOverrideService
  │  ├─ Depends on: SimCtlService
  │  └─ Publishes: appearance, contrast, etc. (9 toggles)
  │
  ├─ StatusBarService
  │  ├─ Depends on: SimCtlService
  │  └─ Publishes: isApplying, lastError
  │
  └─ CameraService
     ├─ Uses: AXUIElement AX menu traversal
     └─ Publishes: isFrontEnabled, isBackEnabled
